# Apple Products Pricing Dashboard (2020–2026)

An interactive **Power BI** dashboard that analyzes Apple product pricing, discounts, and sales performance across product categories, sale events, and e-commerce platforms.

![Dashboard Preview](screenshot.png)

## Overview

The dashboard explores how Apple product prices change over time and how sale events and platforms affect revenue and discounts. It helps answer:

- How much revenue is generated each **year**?
- Which **product categories** (iPhone, Mac, iPad, Watch) see the largest price drops?
- Which **sale events** (Black Friday, Prime Day, Big Billion Days, Great Indian Festival) drive the most revenue?
- How do **Amazon** and **Flipkart** compare in price drops?

##  Key Metrics

| Metric | Value |
|---|---|
| Average Rating | 4.45 |
| Average Reviews Count | 2.41K |
| Price Retention | 81.20% |
| Average Discount | 21.42% |

##  Visuals Included

- **KPI cards** – average rating, average reviews count, price retention, average discount
- **Total Revenue (USD) by Year**
- **Total Price Drop (USD) by Product Category**
- **Total Revenue (USD) by Sale Event**
- **Total Price Drop (USD) by Platform**
- **Slicers** – filter by *Model Name* and *Quarter*

## 🛠️ Tools

- Microsoft Power BI Desktop
- DAX measures and data modeling

##  How to Use

1. Clone or download this repository.
2. Open `Apple Dashboard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
3. Use the slicers to explore the data.
